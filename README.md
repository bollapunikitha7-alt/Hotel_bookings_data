# Hotel Business Analysis using Python

## Project Overview
This project analyzes hotel booking data to identify customer behavior, booking trends, cancellation patterns, and pricing strategies. A Random Forest Machine Learning model is used to predict booking cancellations.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Features
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Business Insights
- Machine Learning Prediction
- Feature Importance Analysis
